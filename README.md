# Permissões de arquivos no Linux

Projeto prático sobre gerenciamento de permissões de arquivos e diretórios no Linux utilizando Shell Bash.

## Sobre o projeto

Este projeto demonstra alguns comandos utilizados para visualizar e administrar permissões de arquivos e diretórios para usuários e grupos.

Os comandos foram realizados em um laboratório do curso **Tools of the Trade: Linux and SQL**, da Coursera.

## Conteúdos abordados

- Verificação de arquivos e diretórios com `ls`
- Visualização de arquivos ocultos com `ls -a`
- Visualização detalhada de permissões com `ls -l`
- Interpretação de strings de permissões
- Alteração de permissões utilizando `chmod`
- Alteração de permissões de arquivos ocultos
- Alteração de permissões de diretórios

## Objetivo

Praticar conceitos de gerenciamento de permissões no Linux e compreender como o controle de acesso contribui para a segurança dos sistemas.
